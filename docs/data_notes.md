## Test-label policy

`test.csv` values are reserved for final evaluation and are summarised only by
counts. The `train.csv` row for `24158401-Rental-Agreement` describes a document in
`test/`, so it is treated as a test label as well.

*Disclosure:* during project setup (Prompt 1) the raw contents of `test.csv` were
printed once while inspecting the files. They have not been used for any design
decision, and notes derived from them have been removed from this file.

## What the labels mean (from train documents only)

- **Aggrement Value**: monthly rent, digits only. When digits and words disagree, the digits win.
- **Aggrement Start Date**: tenancy commencement date if stated, else execution date; `DD.MM.YYYY`.
- **Aggrement End Date**: stated end date, else derived from start + term.
- **Renewal Notice (Days)**: in practice the **termination/vacating notice** period in days
  (1 month = 30). `47854715` has both a 2-month termination clause and a 1-month renewal
  clause; its label is 60.
- **Party One / Party Two**: lessor/owner and lessee/tenant. Name formatting is inconsistent.

## Documents

- Test DOCX files have a double extension (`.pdf.docx`); `src.dataset.document_id` strips both.
- DOCX files were converted from PDFs; 7 of 12 contain **text boxes**, which
  python-docx's `Document.paragraphs` skips. `src.document_reader` reads them.
- Some DOCX text is itself noisy OCR (e.g. `rEST"° LANDLORD` in `44737744`).
- PNG scans are single tall pages (up to 2550x6600) with large blank areas.
